# 战双帕弥什 RPA 全自动主线助手 🚀

一个帮你全自动推战双主线剧情/关卡的脚本。
遇到复杂互动无法通过的关卡，脚本会自动跳过并继续推后面的关卡，直到通过所有能通过的副本。

## 用前须知：
1. **本项目仅测试过Windows系统，其他系统运行效果未知**。
2. **脚本可在真机或模拟器上运行，但推荐在模拟器上运行**，真机上运行一旦屏幕比例非标准16:9，很可能会出现识别错误。
## 🛠️ 如何使用？

1. **游戏准备**：电脑打开模拟器，进入《战双帕弥什》，并使游戏处于首页界面
2. **一键启动**：下载本项目的 Release 压缩包，解压到本地，直接双击运行里面的 **`战双.exe` 文件**即可。
3. **adb设备选择**：如果电脑只运行了一个模拟器，脚本会自动选择该模拟器；如果电脑运行了多个模拟器，需要手动选择要操作的模拟器设备。
4. **脚本运行**：选择好设备后，脚本会自动开始运行
